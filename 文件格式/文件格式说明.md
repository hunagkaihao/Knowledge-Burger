# .pdb（Progarm Database）

`概念`：PDB 文件时编译过程中生成的符号文件，用于将源代码与编译后的二进制代码建立映射关系。它包含了源文件路径、行号、变量名称、函数签名、调用堆栈信息等，让调试器能够在运行时精确定位代码位置并查看变量状态

`主要作用`：

1. 本地调试：在 Debug 模式下，PDB 文件充当源码与 DLL/EXE 之间的桥梁，使断点、变量监视、异常定位成为可能。

2. 第三方库调试：若要在本地调试外部 DLL，需要对应的 PDB 文件才能进入其源码级调试。

3. 错误分析：即使在 Release 模式，PDB 也能记录错误发生的行号，方便崩溃分析。

# .bak

**.bak文件**是一种备份文件，通常用于存储数据的副本。这些文件的主要目的是在数据丢失或损坏时提供恢复的可能性。

# .ldb

LDB文件是Microsoft Access数据库在多用户环境下生成的锁定文件，用于记录当前正在访问数据库的用户和事务。

## LDB文件的定义与作用

LDB文件，也称为锁定文件，是在打开Access数据库（.MDB文件）时自动生成的临时文件，用于**管理多用户访问和防止数据冲突**。它主要有两个作用：

1. **锁定机制**：确保同一时间只有一个用户可以编辑数据库的特定部分，从而避免数据损坏和不一致性。
2. **记录访问信息**：跟踪哪些记录集或对象（如表、查询、表单、报表）正在被用户访问，以便数据库在用户尝试修改时做出正确响应。

## LDB文件的生成与删除

- 当用户打开一个Access数据库时，系统会在数据库所在目录生成一个同名的LDB文件。
- LDB文件会随着最后一个用户关闭数据库而自动删除。
- 如果数据库异常关闭或用户权限不足，LDB文件可能不会被删除，需要手动处理。 

## LDB与MDB文件的区别

- **MDB文件**：Access数据库的主文件，存储实际数据、表结构、查询、表单和报表等，是数据库的核心。
- **LDB文件**：辅助文件，用于锁定和记录访问信息，保证多用户环境下的数据一致性和完整性。
- 一个MDB文件对应一个LDB文件，LDB文件只在数据库被打开时存在

# INI 文件

INI文件，全称为Initialization File，是一种初始化文件，主要用于Windows操作系统中的系统配置。INI文件以纯文本格式存储，通常包含多个节(section)，每个节包含多个键(key)和值(value)对，用于设置程序或系统的参数。
