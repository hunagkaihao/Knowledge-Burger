# I²C

`概念`：I²C（Inter-Integrated Circuit，也写作 I2C 或 IIC）是一种由 Philips（现 NXP）开发的**同步、半双工、多主多从**的串行通信总线，广泛用于连接低速外设（如传感器、EEPROM、RTC 等）。其通信依赖严格的**时序控制**，主要通过两根线完成：

- **SDA（Serial Data Line）**：数据线
- **SCL（Serial Clock Line）**：时钟线（由主设备产生）

## **一、I2C 基本时序要素**

I2C 的通信由以下关键事件组成，按顺序发生：

### **1.** ***起始条件（START Condition）***

- **定义**：当 SCL 为高电平时，SDA 从高电平**跳变到低电平**。
- **作用**：标志一次通信的开始。
- **注意**：必须在 SCL 高期间完成 SDA 下降沿。

```
SCL: ────┬───────
         │
SDA: ────┘───────  ← 起始条件（高→低，SCL=高）
```

### **2.** ***地址帧 + 读写位***

- 主设备发送 7 位从机地址 \+ 1 位读写方向位（R/W）：
  - `0` 表示**写**（主 → 从）
  - `1` 表示**读**（主 ← 从）
- 共 8 位，MSB 先传。

### **3.** ***应答位（ACK / NACK）***

- 每个字节（8 位）传输后，接收方需在第 9 个时钟周期拉低 SDA 表示 **ACK（Acknowledge）**。
- 若 SDA 保持高，则为 **NACK（Not Acknowledge）**，表示无响应或传输结束。

### **4.** ***数据传输***

- 数据在 SCL 为**低电平**时变化，在 SCL 为**高电平**时稳定并被采样。
- 每次传输 8 位（1 字节），MSB 先传。

### **5.** ***停止条件（STOP Condition）***

- **定义**：当 SCL 为高电平时，SDA 从低电平**跳变到高电平**。
- **作用**：标志通信结束。

```
SCL: ────────┬────
             │
SDA: ────────└────  ← 停止条件（低→高，SCL=高）
```

## **二、完整通信流程示例（主写数据到从机）**

1. 主设备发出 **START**
2. 主发送 **7-bit 地址 + R/W=0（写）**
3. 从机匹配地址后，拉低 SDA 发送 **ACK**
4. 主发送 **数据字节 1**
5. 从机回复 **ACK**
6. （可重复步骤 4–5 发送多个字节）
7. 主发出 **STOP**

> 若是读操作（R/W=1），则在地址 ACK 后，从机开始驱动 SDA 发送数据，主设备负责 ACK/NACK 和 STOP。
