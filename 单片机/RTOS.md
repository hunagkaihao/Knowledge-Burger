# RTOS 基础知识

### **引言**

**RTOS（Real-Time Operating System）**，即 **实时操作系统**，是一种专为**实时应用**设计的轻量级操作系统内核。它运行在微控制器（如 STM32、ESP32、ARM Cortex-M 等）上，用于**管理多个任务（线程）、资源调度、时间控制和事件响应**。

### **RTOS 的核心特性**

### **1.** ***\*多任务（Multitasking）\****

- 允许将程序拆分为多个独立任务
- RTOS 内核负责在任务间**快速切换**（上下文切换）

### **2.** ***\*实时性（Real-Time）\****

- **硬实时（Hard Real-Time）**：必须在截止时间内完成，否则系统失效（如刹车控制）
- **软实时（Soft Real-Time）**：允许偶尔超时，但尽量满足（如音频播放）
- RTOS 保证**高优先级任务能及时获得 CPU**

### **3.** ***\*任务调度（Scheduler）\****

- 基于

  优先级抢占式调度

  （最常见）：

  - 高优先级任务就绪 → 立即打断当前任务
  - 相同优先级 → 时间片轮转或协作式

- 例如：电机控制任务（高优先级） vs 日志打印任务（低优先级）

### **4.** ***\*同步与通信机制\****

RTOS 提供标准工具解决任务间协作问题：

| 机制                          | 用途                                      |
| :---------------------------- | :---------------------------------------- |
| **信号量（Semaphore）**       | 控制资源访问数量（如最多3个任务访问外设） |
| **互斥锁（Mutex）**           | 保护共享资源（如全局变量），防止冲突      |
| **消息队列（Message Queue）** | 任务间传递数据（如传感器→控制算法）       |
| **事件标志（Event Flags）**   | 通知多个任务某个事件发生                  |
| **邮箱、流缓冲区等**          | 更高级的数据传递方式                      |

### **5.** ***\*确定性（Determinism）\****

- 行为可预测：任务切换时间、中断响应时间有上限
- 这是普通操作系统（如 Windows、Linux）不具备的





---

**osDelay**:是一个用于实现任务延时的函数。

# CMSIS-RTOS基础知识

**前言**：CMSIS-RTOS 是 **ARM 公司为 Cortex-M 系列微控制器定义的一套标准化的实时操作系统（RTOS）应用程序接口（API）**。它的核心目标是：**让开发者编写的 RTOS 代码与底层具体 RTOS 内核（如 FreeRTOS、RTX、Zephyr 等）解耦，实现“一次编写，随处移植”**。

| 版本          | 特点                                            | 现状                           |
| ------------- | ----------------------------------------------- | ------------------------------ |
| CMSIS-RTOS v1 | 基于 Keil RTX 设计，API 较老                    | 已弃用，不推荐新项目使用       |
| CMSIS-RTOS v2 | ARM 重新设计，支持现代 C 标准、更安全、功能更强 | 当前标准，STM32CubeMX 默认生成 |



**CMSIS（Cortex Microcontroller Software Interface Standard）** 是由 **ARM 公司制定的一套标准化软件接口规范**，旨在为基于 **ARM Cortex-M 系列处理器**（如 Cortex-M0/M3/M4/M7 等）的微控制器（MCU）提供统一、可移植、高效的软件开发基础。
