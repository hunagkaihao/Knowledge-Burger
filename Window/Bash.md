**Bash** 是 **Bourne Again SHell** 的缩写，它是 Linux 和 macOS（以及 Windows 的 WSL 子系统）中最常用、最强大的**命令行解释器**。

简单来说，你可以把它理解为一种通过**输入文本指令**与操作系统进行交互的方式，而不是用鼠标点击图形界面。



# grep

在早期的 Unix 文本编辑器 `ed` 中，有一个命令是：

```bash
g/re/p
```

- **g**：全局 (global)
- **re**：正则表达式 (regular expression)
- **p**：打印 (print)

**`grep` 就是在文本里“按关键词筛选行”的工具，是命令行世界的 Ctrl+F。**

想象你有一个名为 `myfile.txt` 的文件，内容如下：

```
苹果很好吃
我喜欢吃香蕉
橘子也不错
我最爱吃苹果派
```

如果你运行：

```
grep "苹果" myfile.txt
```

`grep` 会找出所有包含“苹果”的行并显示：

```
苹果很好吃
我最爱吃苹果派
```

（它不会显示“香蕉”或“橘子”那两行）

# *

**通配符 `\*`**：`rm *.jpg` 表示删除所有以 `.jpg` 结尾的文件。

# |

**管道 `|`**：可以把一个命令的输出作为另一个命令的输入。例如 `ls -l | grep "你好"` 会从文件列表中只筛选出包含“你好”的行。
