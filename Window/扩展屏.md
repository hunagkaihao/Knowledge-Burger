# 软件跑丢

这个方法通过键盘强制进入窗口的“移动模式”，然后用鼠标把窗口拖回来。请按以下步骤操作：

1. **选中目标软件**：在任务栏上点击一下那个“跑丢”了的软件图标，确保它是当前选中的状态（或者按 `Alt + Tab` 切换到该程序）。
2. **呼出系统菜单**：按下键盘上的 **`Alt + 空格`** 组合键（此时可能在屏幕边缘看不到菜单，没关系，继续下一步）。
3. **进入移动模式**：紧接着按一下键盘上的 **`M`** 键（代表“移动/Mobile”）。
4. **激活抓取**：随便按一下键盘上的 **方向键**（比如按一下 `←` 左方向键或 `→` 右方向键）。这一步非常关键，它会让你的鼠标指针和那个隐藏的窗口产生“吸附”关联。
5. **拖回窗口**：现在，**直接移动你的鼠标**（不要按鼠标按键），你会发现那个消失的窗口已经粘在你的鼠标指针上回到了主屏幕。在合适的位置点击鼠标左键放下即可。
