# 安装 Windows 系统

一、方法 A：系统内重置（推荐，不用 U 盘）

适合：能正常开机、想快速格式化 C 盘 + 重装系统

1. 按 `Win+I` → **系统** → **恢复**

   ![](D:\Project\Knowledge-Burger\Picture\Window\重装系统1.png)

2. 点 **重置此电脑 → 开始**

3. 选：**删除所有内容**（彻底清空）

4. 下一步选：**本地重新安装**

5. 按提示走 → 自动格式化 C 盘、重装系统

6. 完成后：装驱动 → 配开发环境

 二、方法 B：U 盘全新安装（最纯净，技术岗常用）

**准备**

- 8GB+ U 盘（会清空）
- 另一台能上网的电脑

**步骤 1：制作安装 U 盘（用另一台电脑）**

1. 去微软官网下载 **Media Creation Tool**

   

   - Win10: https://www.microsoft.com/zh-cn/software-download/w10
   - Win11: https://www.microsoft.com/zh-cn/software-download/w11

   ![](D:\Project\Knowledge-Burger\Picture\Window\重装系统2.png)

2. 运行 → **为另一台电脑创建安装介质**

3. 选 **Windows 11/10 专业版 / 企业版（公司常用）、64 位**

4. 插入 U 盘 → 选 **U 盘** → 等待制作完成

**步骤 2：用 U 盘启动安装（你自己电脑）**

1. 插入 U 盘 → 重启

2. 开机狂按 

   启动热键

   - 联想 / 戴尔 / 华硕：F12
   - 惠普：F9
   - 宏碁：F12
   - 笔记本：可能要按 Fn+F12

3. 选 **UEFI: U 盘名称** 启动

4. 安装界面：**现在安装** → 输入密钥（公司一般有批量密钥）

5. 分区：**删除原来的 C 盘和系统相关分区** → **新建** → **格式化**

6. 选新建的分区 → 下一步安装

**步骤 3：安装后**

- 装：**主板 / 显卡 / 网卡驱动**
- 配：**JDK/Git/IDE/ 数据库 / 编译环境**等

## 磁盘内存分配

C盘：200GB ——》存放系统文件

D盘：200GB ——》存放工作文件

E盘：100GB ——》存放安装的软件

# 安装 Linux 系统

### **一、安装前必做：关闭Windows快速启动与BitLocker**

- **关闭快速启动**：进入“控制面板 > 电源选项 > 选择电源按钮的功能”，取消勾选“启用快速启动”，否则Linux无法识别磁盘分区。
- **关闭BitLocker**：若C盘启用了加密，需先解密完成再操作，否则Linux安装程序会报错。

### **二、分区建议：预留80GB以上空间**

- 使用Windows“磁盘管理”压缩现有分区（如D盘），释放至少80GB未分配空间。
- 不建议手动创建Linux分区，安装时由Ubuntu自动分配更稳妥。

### **三、制作启动U盘：选对架构与工具**

- 下载Ubuntu 24.04 LTS的**Intel or AMD 64-bit**版本（5.9GB），红魔16 Pro为x86_64架构，ARM版不适用。
- 使用Rufus写入U盘，分区类型选GPT，引导模式选UEFI。

### **四、BIOS设置：关闭安全启动**

- 开机按F2或Del进入BIOS，找到“Secure Boot”选项并设为Disabled。
- 确认启动模式为UEFI，避免Legacy模式导致引导失败。

### **五、安装过程：选择“安装Ubuntu alongside Windows Boot Manager”**

- 安装程序会自动识别Windows分区，选择“与Windows共存”选项。
- 若提示“无法识别EFI分区”，需手动指定EFI系统分区（通常为100-500MB的FAT32分区）。



### **第一步：在 BIOS 中设置 U 盘为第一启动项**

1. 用方向键切换到 **Boot** 选项卡
2. 找到 **Boot Option #1**（第一启动项），按回车
3. 在弹出的列表中选择你的 U 盘（通常显示为 "UEFI: SanDisk" 或 "USB Device" 之类的名称）
4. 按 **F10**（或 F4，看界面底部提示）保存并退出

> 电脑会自动重启，并从 U 盘引导进入 Linux 安装界面。

------

### **第二步：进入 Linux 安装界面**

重启后你会看到 GRUB 引导菜单：

1. 选择 **"Try or Install Ubuntu"**（或对应发行版名称），按回车
2. 等待加载完成，进入安装向导

------

### **第三步：安装向导操作（以 Ubuntu 为例）**

#### **1. 选择语言**

- 左侧选择 **"中文（简体）"**
- 点击 **"安装 Ubuntu"**

#### **2. 键盘布局**

- 默认选择 **Chinese**，直接点 **"继续"**

#### **3. 应用和更新**

- 选择 **"正常安装"**
- 勾选 **"为图形或无线硬件安装第三方软件"**（这一步很重要，会自动安装显卡和 Wi-Fi 驱动）
- 点击 **"继续"**

#### **4. 安装类型（⚠️ 关键步骤）**

根据你的需求选择：

**方案 A：双系统（保留 Windows）**

- 选择 **"与 Windows 共存"**，系统会自动在之前预留的空闲空间上安装

**方案 B：手动分区（推荐，更灵活）**

- 选择 **"其他选项"**，进入手动分区界面
- 找到之前压缩出的 **"空闲空间"**，依次创建以下分区：

表格

| 分区         | 大小       | 类型  | 挂载点    |
| :----------- | :--------- | :---- | :-------- |
| EFI 系统分区 | 512MB      | FAT32 | /boot/efi |
| 交换分区     | 8~16GB     | swap  | —         |
| 根分区       | 至少 100GB | ext4  | /         |
| 用户分区     | 剩余空间   | ext4  | /home     |

> ⚠️ 底部 **"安装启动引导器的设备"** 选择你的主硬盘（如 `/dev/nvme0n1`），不要选具体分区号。

**方案 C：整盘安装（清空所有数据）**

- 选择 **"清除整个磁盘并安装 Ubuntu"**
- ⚠️ 这会删除所有数据，务必提前备份

#### **5. 时区设置**

- 在地图上点击中国区域，或手动选择 **"Shanghai"**

#### **6. 用户信息**

- 设置你的 **用户名** 和 **密码**
- 可勾选 **"自动登录"** 省去每次输密码
- 点击 **"安装"**

#### **7. 等待安装完成**

- 安装过程大约 10~30 分钟
- 完成后会提示 **"安装完成"**
- **拔掉 U 盘**，点击 **"现在重启"**

------

### **第四步：重启后**

重启后你会看到 **GRUB 引导菜单**：

- 默认选项是 **Ubuntu**，直接回车进入
- 如果想回 Windows，选择 **"Windows Boot Manager"** 即可
