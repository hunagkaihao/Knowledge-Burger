# Emacs 介绍

Emacs 是一个文本编辑器系列，包含有多个分支，其中最主流的一支是 [GNU Emacs](http://link.zhihu.com/?target=https%3A//www.gnu.org/software/emacs/)，大多数情况下所说的 Emacs 都是指 GNU Emacs。

Emacs 这一名字最早来源于 “Editor MACroS”，后来也有人称它集合了五个主要功能键的首字母 Esc、Meta、Alt、Ctrl、Shift。

# 功能键

| Emacs 功能键 | 缩写 | 对应键盘按键(PC/Mac) |
| ------------ | ---- | -------------------- |
| Control      | C    | Ctrl / Control       |
| Meta         | M    | Alt / Option         |
| Shift        | S    | Shift / Shift        |
| Super        | s    | Win / Command        |
| Hyper        | H    | 无                   |

# 命令

| 名称     | 快捷键                                                       |
| -------- | ------------------------------------------------------------ |
| C-g      | 中断命令                                                     |
| C-x或C-c | 退出程序                                                     |
| C-z      | 挂起程序                                                     |
| C-p      | 方向键前（previous）                                         |
| C-n      | 方向键后（next)                                              |
| C-b      | 方向键左（back)                                              |
| C-f      | 方向键右（forward)                                           |
| M-b      | 光标向左移动一个词                                           |
| M-f      | 光标向右移动一个词                                           |
| C-a      | 光标移至行首                                                 |
| C-e      | 光标移至行尾                                                 |
| M-a      | 光标移至句首                                                 |
| M-e      | 光标移至句尾                                                 |
| M-<      | 光标移动到文件开头（Meta键+Shift键+逗号）                    |
| M->      | 光标移动到文件末尾（Meta键+Shift键+句号）                    |
| M-r      | 按第一次——光标移动到窗口中间行；接着按第二次——光标移动到窗口最上面一行；接着按第三次——光标移动到窗口最下面一行 |
