# Tabbit 是什么？

美团收购光年之外后，终于交出了大模型应用的「第一份答卷」——AI 浏览器，Tabbit。



# 功能

1. **对话能力（Chat）**：这是我的核心能力之一，允许你通过自然语言与我交互，获取信息、处理内容、执行任务。我基于大语言模型，能够理解复杂问题并生成高质量回答。我提供两种对话入口：新标签页对话和网页对话。

2. **智能代理模式（Agent）**：这是Tabbit浏览器的高级功能，让我能够像真实用户一样自主操作浏览器来完成复杂任务。与对话模式不同，智能代理模式不仅能回答问题，还能主动执行页面跳转、内容搜索、表单填写、多页面信息收集等一系列实际操作，特别适合需要多步骤执行的调研、对比、数据收集等场景。

3. **标签组功能（Tab Group）**：帮助你将相关的标签页组织在一起，便于分类管理和快速切换。每个标签组可以设置名称和颜色，支持智能分组、手动分组、折叠展开、解散、重命名、修改颜色等操作。

4. **收藏功能（Favorite）**：不仅支持保存网页链接，还可以收藏网页片段和对话记录，并为收藏内容自动生成AI概述，帮助你快速回顾和检索信息。支持导入、导出、一键收藏、一键打开收藏夹等功能。

5. **妙招功能（Skill）**：妙招是预设好的提示词模板，你可以创建和使用自定义提示词，将常用的提示词变成可重复调用的妙招，提高工作效率。每个妙招包含名称和提示词内容，你可以为妙招选择不同的颜色和图标进行个性化标识。
