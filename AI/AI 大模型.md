# AI 大模型汇总

## Mimo

**Mimo 是小米公司研发的开源大模型，由小米大模型Core团队开发。**

Mimo 是 **小米公司于2025年4月30日开源的首个推理大模型**，参数规模为7B，由小米大模型Core团队研发。该团队由雷军于2023年推动成立，致力于语言、多模态、语音等领域的突破 。Mimo 模型通过预训练与后训练联动机制提升推理能力，在数学推理和代码竞赛中表现优异，超过了 OpenAI o1-mini 和阿里 Qwen QwQ-32B-Preview。

**模型版本与特点**

- **MiMo-V2.5**：支持图像、视频、音频、文本的原生理解，适合多模态 Agent 场景，支持超长上下文（1M token）和长程推理。
- **MiMo-V2.5-Pro**：旗舰级 Agent 大模型，采用稀疏 MoE 架构，总参数1.02T，激活参数42B，专为复杂软件工程与长程任务设计，可支持多轮工具调用和长上下文任务。
- **MiMo-V2-Flash 和 MiMo-Embodied**：总参数量达3090亿，激活参数150亿，专为智能体 AI 设计，采用多层 Multi-Token Prediction（MTP）模块和混合注意力架构，实现高效推理。

**应用场景**

Mimo 模型已应用于小米 HAD 辅助驾驶系统、智能家居方案（Xiaomi Miloco）、AI交互测试产品（Xiaomi miclaw）等 。其多模态理解能力和长程推理能力，使其在复杂任务、长文本分析、长视频追踪以及多步骤工具调用中表现出色。
综上，**Mimo 是小米公司自主研发的多模态大模型系列**，覆盖从基础推理到旗舰级 Agent 的多种版本，广泛应用于智能家居、辅助驾驶和软件工程等场景。

## DeepSeek

**DeepSeek** 是由北京深度求索人工智能基础技术研究有限公司开发的一款基于Transformer架构的大型语言模型。它具备强大的自然语言理解和生成能力，能够处理多种复杂的语言任务，如智能对话、文本生成、语义理解等。

DeepSeek-V3

**DeepSeek-V3** 是DeepSeek大模型的最新版本，于2024年12月16日发布。它在架构上进行了多项创新，采用了更深的网络结构和更大的模型规模，以进一步提高模型的性能。DeepSeek-V3引入了多头潜在注意力机制（MLA），通过压缩键和值为低秩潜在向量来降低内存占用，从而能够处理更长的序列。

关键技术

**Transformer架构**：DeepSeek-V3采用了Transformer架构，摒弃了传统的循环神经网络（RNN）和卷积神经网络（CNN）结构，采用了全新的自注意力机制，能够并行处理输入序列中的每个元素，从而大大提高了模型的计算效率。**Mixture-of-Experts（MoE）架构**：DeepSeek-V3引入了MoE架构，将模型划分为多个专家子模型，每个子模型负责处理不同的输入任务。通过引入MoE架构，DeepSeek-V3能够更高效地利用计算资源，提高模型的泛化能力和鲁棒性。**Multi-Token Prediction（MTP）**：MTP机制通过在训练过程中预测多个未来的token来增强模型的文本生成能力，使得DeepSeek-V3在生成连贯、流畅和准确的文本方面表现出色。**稀疏注意力机制**：稀疏注意力机制通过仅关注最相关的token来减少注意力计算的数量，从而降低计算开销，使得DeepSeek-V3在处理大规模数据集时更加高效和稳定。

应用场景

DeepSeek-V3在多个领域具有广泛的应用前景，包括智能对话、文本生成、语义理解、代码生成补全以及多模态输入支持（如图像、音频等）。

## Claude Sonnet

Claude Sonnet 4是由人工智能公司**Anthropic**于2025年5月23日推出的新一代AI大模型，属于Claude 4系列的核心产品之一，定位为企业级应用的“全能主力”。
