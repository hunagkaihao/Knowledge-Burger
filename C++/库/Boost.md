# Boost.Log

Boost.Log 是 Boost 库中功能强大的日志记录组件，提供了灵活的日志配置，适用于调试、监控和生产环境日志管理。与标准库的 std::cout 或简单文件输出相比，Boost.Log 支持多线程、异步日志、过滤器、格式化以及多种输出目标（如文件、控制台、网络）。

## 核心概念

1. 日志记录（Record）：一条日志消息，包含消息内容和属性（如时间戳、级别）。

2. 日志源（Source）：生成日志的地方，如 BOOST_LOG_TRIVIAL(info)。

3. 日志接收器（Sink）：日志输出目标，如文件或控制台。

4. 过滤器（Filter）：决定哪些日志记录被输出。

5. 格式化器（Formatter）：定义日志输出格式。

6. 核心（Core）：管理日志系统，连接源和接收器。

## 功能

1. 异步日志：使用异步接收器，减少 I/O 阻塞。

2. 自定义过滤器：筛选 info 级别以上的日志，附加线程 ID 属性。

3. 自定义格式：输出格式为 [时间戳][线程 ID][级别]: 消息。

4. 多输出目标：同时输出到文件（app.log）和控制台。

5. 集成示例：将日志配置集成到 TCP 服务器，记录连接和消息。
