# WMS  (Warehouse Management System)
 **WMS (Warehouse Management System)**：仓库管理系统。了解基本流程：入库 -> 上架 -> 拣选 -> 出库 -> 盘点。

## 特点

1. 掌握库存情况
2. 降低库存损失
3. 提高出库效率
4. 降低人力成本
5. 提升客户 满意程度 

## 入库管理

1. 采购入库单
2. 退料入库单
3. 生产入库单
4. 销售退货入库单
5. 其他入库单

**主要任务**：对货物进行快速、准确的收货、上架质检和入库，并及时更新系统中的库存信息

## 出库管理

1. 采购退货出库单
2. 领料出库单
3. 销售出库单
4. 其他出库单

**主要任务**：对订单进行快速、准确的处理，完成检货打包和发货等操作，并及时更新系统中的库存信息

## 库存管理（核心）

**主要任务**：对仓库的货物进行实时的库存跟踪和管理，并及时更新系统中的库存信息。同时其还可以对库存进行定期盘点，以确保库存数据的准确性和完整性

## 数据报表

1. 货品列表：显示不同货品的种类数量、货品的种类和各类货品的详细信息
