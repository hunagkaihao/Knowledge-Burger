# 快捷键

- Alt  + H + O + I：自动调整列宽
- 选中列，将鼠标移到选中列的**边框线上**，直到光标变成 **四向箭头**（带小十字的移动图标），然后按住Shift：移动选中列到指定列
- Ctrl + 1：自定义格式

# 快速插入每行同样数据

### **使用“自定义单元格格式”（仅改变显示，不改变实际内容）**

如果你只是希望**看起来**后面有 `${05}`，但点击单元格时里面还是原来的数字，可以用这个方法。

1. 选中 B 列的所有数据。

2. 按 **Ctrl + 1** 打开“设置单元格格式”。

3. 在左侧选择 **“自定义”**。

4. 在右侧“类型”框中输入：

   ```
   @"插入的内容"
   
   // 示例
   @"${05}"
   ```

   *(@符号代表原本的文本内容)*

# 单元格自适应内容大小

### **利用 VBA 宏实现“真正”的自动调整**

如果你希望表格在输入数据时能实时、自动地改变列宽，可以使用 Excel 的“宏”（VBA）功能来实现。

**操作步骤：**

1. 在你的 Excel 界面，按快捷键 `Alt + F11` 打开 VBA 编辑器窗口。
2. 在左侧“项目”窗口中，找到你当前的工作表（例如 `Sheet1 (Sheet1)`）。
3. **双击它**，打开代码窗口。
4. 将下面的代码复制并粘贴到右侧的代码窗口中：

```vb
Private Sub Worksheet_Change(ByVal Target As Range)
    ' 当工作表内容发生改变时，自动调整所有已用列的宽度
    Target.EntireColumn.AutoFit
    
    ' 如果你只想自动调整 A、B、C 三列，可以使用下面这行代替：
    ' Columns("A:C").AutoFit
End Sub
```
