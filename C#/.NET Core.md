# .NET Core

`.NET Core`：支持跨平台开发（Windows、Linux、Mac等）

`.NET Framework`：Window平台下的软件开发

`.NET Standard`：类库项目。它制定了一个规范（类、方法等都必须要实现），只是一个标准，不是实现。可以被支持其版本的.NET Framework、.NET Core、 Xamarin等引用

# 发布说明

部署模式

1. 依赖框架：发布的主机需要部署相关的.net 运行时环境
2. 独立：将.net 运行时环境打包到发布文件中
3. ReadyToRun：程序运行时快，但编译时慢
4. 生成单个文件：生成极少文件，适合用于发布可运行包
5. 剪裁未使用的程序集：删去用不到的程序集然后打包
