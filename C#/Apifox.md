# Apifox初识

### **第 1 步：创建你的专属项目**

1. 打开 Apifox 客户端，在首页点击 **“新建项目”**。
2. 在弹出的窗口中输入项目名称（例如：“新手实战练习”），点击“确定”。
3. 进入项目后，你会看到左侧是导航栏，中间是主要工作区，右侧是文档和辅助区。

### **第 2 步：设计并新建一个接口**

1. 在左侧导航栏，将鼠标悬停在“接口”上，点击右侧出现的 **“+”** 号，选择 **“新建接口”**。
2. 在中间的编辑区填写基础信息：
   - **接口名称**：填写“获取用户信息”。
   - **请求方法**：选择 `GET`。
   - **接口路径**：填写 `/users/{id}`（注意：`{id}` 是一个路径变量，代表我们要查询的用户ID），在接口编辑区，会自动生成 **“Path”** 标签（因为我们路径里用了 `{id}`）。

### **第 3 步：配置环境与变量（告别重复输入）**

1. 点击界面左上角的 **“环境”** 下拉框，选择 **“新建环境”**。

2. 命名为“测试环境”，在全局变量中添加一个变量：

   - 默认模块：`https://jsonplaceholder.typicode.com`（这是一个免费的公开测试接口网站）

   - 点击“保存”。

     ![](D:\Project\Knowledge-Burger\Picture\Apifox\环境管理.png)

3. 选择对应环境，回到刚才的接口页面，在最上方的 URL 栏会默认选择刚才添加的默认模块。

   ![](D:\Project\Knowledge-Burger\Picture\Apifox\环境管理1.png)

### **第 4 步：填写参数并发送请求**

1. 点击“添加参数”，参数名填写 `user_id`，示例值填写 `1`。

2. 点击右上角的 **“发送”** 按钮（或使用快捷键 `Ctrl + Enter` / `⌘ + Enter`）。

3. 观察下方的 **“响应结果”**，你会看到服务器成功返回了 ID 为 1 的用户 JSON 数据，状态码为 200。

   ![](D:\Project\Knowledge-Burger\Picture\Apifox\发送.png)
