# 二极管

`概念`：二极管是一种常用的具有一个 PN 结的半导体器件，它具有单向导电性，通过二极管的电流只能向一个方向流动。二极管只有在加上正向电压并达到一定值的时候才会导通。

# 二极管的特性

1. `单向导电性`：二极管正偏导通（正极电位高于负极电位），反偏截止（正极电位低于负极电位）
2. `伏安特性`：二极管两端的电压和流过的电流之间的关系曲线
   - 正向特性：二极管正偏时电阻小，具有非线性
   - 反向特性：二极管反偏时电阻大，存在电击穿现象



1. 二极管实际上不具有电阻（因而它不遵从欧姆定律）
2. 如果把一个二极管接到某电路，则该电路将没有戴维南等效电路

# 整流

由于二极管具有单向导电性，所以可以将二极管组成整流电路，将交流电变成单向脉冲电压。

1. 半波整流电路：在交流电压正半周期时二极管导通，有输出；在交流电压负半周期时二极管截止，无输出。经过二极管整流后原来的交流波形变成了缺少半个周期的波形，称之为半波整流。

2. 全波整流电路：以变压器的二次绕组中间的抽头为基准所构成的全波整流电路。

   全波整流电路需要变压器有一个使两端对称的二次绕组中心抽头，这给制作带来很多的麻烦。另外，在这种电路中，每只整流二极管承受的最大反向电压是变压器二次电压最大值的两倍，因此需用能承受较高电压的二极管。

# 检波

运用二极管的单向导电性去掉负半周电流。

多用于无线电信号的接收和放大上。
