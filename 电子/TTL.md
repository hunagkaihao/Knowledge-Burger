TTL（**Transistor-Transistor Logic**，晶体管-晶体管逻辑）是一种经典的**数字集成电路技术**，广泛应用于20世纪60年代至90年代的数字系统中。它以**双极型晶体管（BJT）** 为核心元件，实现逻辑门（如与非门、或非门等）和各类数字功能。

虽然如今CMOS技术已成主流（如74HC系列），但TTL仍在教学、老旧设备维护及特定高速场景中具有重要意义。

## **一、TTL电路的核心特点**

| 特性         | 说明                                                         |
| :----------- | :----------------------------------------------------------- |
| **核心器件** | NPN型双极结型晶体管（BJT）                                   |
| **电源电压** | 标准为 **+5V ±5%**（典型值5V）                               |
| **逻辑电平** | - 高电平（VOH）：≥2.4V（通常3.5V左右） - 低电平（VOL）：≤0.4V - 输入高电平（VIH）：≥2.0V - 输入低电平（VIL）：≤0.8V |
| **噪声容限** | 约0.4V（较低，抗干扰能力弱于CMOS）                           |
| **功耗**     | 较高（每个门静态功耗约10mW）                                 |
| **速度**     | 较快（标准TTL门延迟约10ns，高速系列更快）                    |
| **扇出能力** | 一般为10（即一个输出可驱动10个同类输入）                     |

> ✅ **“TTL电平”** 已成为一种通用术语，泛指以5V为高电平、0V为低电平的数字信号标准（即使实际使用CMOS芯片）。
