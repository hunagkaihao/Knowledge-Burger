# 终端电阻（Termination Resistor）

是用于匹配传输线特性阻抗的电阻元件，主要作用是消除或减少信号在高速传输过程中因阻抗不匹配而产生的反射、振铃、过冲和下冲等信号完整性问题。它广泛应用于高速数字电路、通信系统、总线接口（如CAN、RS-485、以太网等）以及射频（RF）电路中。

### **一、基本原理**

当信号沿传输线传播时，若传输线末端的负载阻抗与传输线的特性阻抗不一致，就会发生**信号反射**。这种反射会导致：

- 波形失真
- 误码率升高
- 通信失败

通过在传输线末端接入一个等于其特性阻抗的电阻（即终端电阻），可使信号被完全吸收，避免反射。

---

### **二、常见应用场景**

1. **CAN总线**
   - 特性阻抗约为120 Ω
   - 通常在总线两端各接一个120 Ω终端电阻，形成并联等效60 Ω（符合CAN标准要求）
2. **RS-485通信**
   - 传输线特性阻抗通常为120 Ω
   - 在通信链路的最远两端加装120 Ω终端电阻
3. **以太网（如100BASE-TX）**
   - 使用内部或外部终端匹配，确保差分信号完整性
4. **高速PCB走线（如DDR内存、PCIe）**
   - 采用端接技术（如串联端接、并联端接、戴维南端接等）

---

### **三、终端电阻的类型**

| 类型       | 说明                                 | 应用场景                        |
| ---------- | ------------------------------------ | ------------------------------- |
| 并联终端   | 电阻连接在信号线与地（或电源）之间   | 简单、常用，但功耗较大          |
| 串联终端   | 电阻串接在驱动端与传输线之间         | 抑制过冲，适用于点对点连接      |
| 戴维南终端 | 由上拉和下拉电阻组成，提供偏置和匹配 | 用于需要偏置电压的总线（如CAN） |
| AC终端     | 电阻与电容串联后接地                 | 减少直流功耗，仅对高频信号端接  |

---

### **四、选型注意事项**

- **阻值匹配**：必须等于传输线的特性阻抗（常见为50 Ω、75 Ω、100 Ω、120 Ω等）
- **功率额定**：需考虑信号幅度和持续电流，避免电阻过热
- **精度与温度系数**：高精度（如±1%）和低温漂电阻更适合高速/精密系统
- **布局位置**：应尽量靠近接收端或总线末端，减少引线电感影响

# PCB 和 PCBA

`PCB（印刷电路板）`：全称Printed Circuit Board，本质是一块没有任何电子元器件的绝缘基板。它就像一座建好的“空房子”，基板（通常是[FR-4玻纤板](https://zhida.zhihu.com/search?content_id=269318012&content_type=Article&match_order=1&q=FR-4玻纤板&zhida_source=entity)）是墙体，表面蚀刻的铜箔线路是预设的“水电管道”，焊盘、过孔则是预留的“零件安装位”。单独的PCB不具备任何电气功能，只能作为电子元器件的固定和连接载体，是电子制造的核心原材料。

`PCBA（印刷电路板组件）`：全称Printed Circuit Board Assembly，是在PCB裸板的基础上，通过[SMT贴片](https://zhida.zhihu.com/search?content_id=269318012&content_type=Article&match_order=1&q=SMT贴片&zhida_source=entity)、[DIP插件](https://zhida.zhihu.com/search?content_id=269318012&content_type=Article&match_order=1&q=DIP插件&zhida_source=entity)、焊接、测试等一系列工序，将芯片、电阻、电容、连接器等电子元器件组装完成后的成品板。如果说PCB是“空房子”，那PCBA就是“装修完毕、可直接入住的成品房”，具备完整的电气功能，是手机、电脑、智能家居、工业设备等电子产品的核心部件。

一句话总结：**PCBA = PCB + 电子元器件 + 组装焊接工艺**，二者是电子制造流程中“前后衔接、从无功能到有功能”的两个关键环节。
