# 网卡

`网卡`（Network Interface Card，简称 NIC），也称为网络接口卡、网络适配器或网络控制器，是计算机或其他网络设备中用于连接网络的硬件组件。它的主要作用是实现计算机与网络之间的数据通信。

一、**网卡的基本功能**

1. **物理连接**
   网卡提供物理接口（如 RJ-45 接口用于有线网络，或天线用于无线网络），使设备能够接入局域网（LAN）、广域网（WAN）或互联网。
2. **数据封装与解封装**
   在发送数据时，网卡将上层协议（如 IP）的数据包封装成适合在物理介质上传输的帧格式（如以太网帧）；接收数据时则进行反向操作。
3. **MAC 地址管理**
   每块网卡都有一个全球唯一的 MAC（Media Access Control）地址，用于在局域网中唯一标识设备，是数据链路层通信的基础。
4. **数据传输控制**
   网卡负责处理底层通信协议（如 CSMA/CD 用于传统以太网），控制数据的发送与接收时机，避免冲突并确保可靠传输。
5. **中断与 DMA 支持**
   现代网卡通常支持直接内存访问（DMA）和中断机制，以高效地与 CPU 协同工作，减少系统资源占用。

二、**网卡的类型**

| 类型     | 特点                                                         |
| -------- | ------------------------------------------------------------ |
| 有线网卡 | 使用网线（如 Cat5e/Cat6）通过 RJ-45 接口连接，稳定、延迟低，常见于台式机、服务器。 |
| 无线网卡 | 通过 Wi-Fi（如 802.11a/b/g/n/ac/ax）连接无线网络，便于移动设备使用。 |
| 集成网卡 | 内置于主板上，成本低、节省空间，大多数现代电脑默认配备。     |
| 独立网卡 | 以 PCIe、USB 等形式外接，性能更强或用于扩展（如多网口服务器、特殊驱动需求）。 |
| 光纤网卡 | 使用光纤接口，适用于高速、长距离传输（如数据中心）。         |

三、**主要用途**

- **上网访问**：让电脑、手机、智能设备等接入互联网。
- **局域网通信**：实现文件共享、打印机共享、内部通信等。
- **服务器连接**：服务器通过高性能网卡提供 Web、数据库、存储等服务。
- **虚拟化与云计算**：支持 SR-IOV、VLAN、负载均衡等高级网络功能。
- **物联网（IoT）**：嵌入式设备通过微型网卡接入网络，实现远程控制与数据采集。

四、**常见技术指标**

- 传输速率：10/100/1000 Mbps（千兆）、2.5G、5G、10G 甚至更高。
- 接口类型：RJ-45、SFP、USB、M.2（用于无线网卡）等。
- 协议支持：Ethernet、Wi-Fi 6/6E/7、Bluetooth（部分无线网卡集成）等。
- 驱动兼容性：需操作系统支持对应驱动程序（Windows、Linux、macOS 等）。
