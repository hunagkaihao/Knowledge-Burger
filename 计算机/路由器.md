# 路由器

路由器（Router）是计算机网络中一种关键的**网络层设备**，主要用于在不同网络之间**转发数据包**，实现多个网络（如家庭局域网与互联网）之间的互联互通。

## **一、路由器的核心功能**

1. **路径选择（路由）**
   路由器根据目标 IP 地址和内部的**路由表**，决定数据包应从哪个接口转发出去，以最有效的方式送达目的地。
2. **连接不同网络**
   路由器可以连接两个或多个逻辑上分离的网络（如你的家庭局域网 LAN 和运营商的广域网 WAN），并在它们之间传递数据。
3. **NAT（网络地址转换）**
   家用路由器通常将多个内网设备（使用私有 IP，如 192.168.1.x）共享一个公网 IP 上网，这就是 NAT 技术，既节省公网 IP，又增强安全性。
4. **DHCP 服务**
   自动为局域网内的设备分配 IP 地址、子网掩码、网关和 DNS 服务器等网络参数，简化配置。
5. **防火墙与安全功能**
   多数路由器具备基础防火墙能力，可阻止外部非法访问，保护内网设备。
6. **无线接入（Wi-Fi）**
   现代家用路由器通常集成**无线接入点（AP）**功能，支持手机、笔记本等设备通过 Wi-Fi 连接网络。
7. **QoS（服务质量）管理**
   可对不同应用（如视频、游戏、下载）分配带宽优先级，优化网络体验。

## **二、路由器 vs 网卡：本质区别**

| 对比项   | 路由器（Router）                         | 网卡（NIC）                                 |
| -------- | ---------------------------------------- | ------------------------------------------- |
| 设备类型 | 独立网络设备（也可集成于光猫、防火墙等） | 计算机内部或外接的硬件组件                  |
| 工作层级 | 网络层（OSI 第3层）                      | 数据链路层（OSI 第2层），部分支持网络层功能 |
| 主要作用 | 在不同网络之间转发数据包，实现跨网通信   | 让单个设备接入网络，收发数据帧              |
| IP 地址  | 通常拥有多个 IP（WAN口 + LAN口）         | 通常只有一个 IP（由 DHCP 或手动配置）       |
| MAC 地址 | 每个物理接口都有独立 MAC 地址            | 一块网卡有一个唯一 MAC 地址                 |
| 是否必需 | 多设备共享上网时必需（或由光猫替代）     | 每台联网设备都必须有（有线/无线形式）       |
| 典型场景 | 家庭宽带出口、企业网络核心               | 电脑、手机、服务器等终端设备内部            |
