# 通过 Windows 系统设置查看

1. 在 Windows 搜索栏输入 **“查看网络连接”** 或 **“ncpa.cpl”** 并回车，打开“网络连接”窗口。
2. 在适配器列表中，寻找名为 **“VirtualBox Host-Only Network”** 的网络连接。
3. 你可以右键点击它，选择 **“状态”** -> **“详细信息”**，来查看它的具体 IP 地址等属性。

# 端口转发
**端口转发是一种将网络流量从一个端口重定向到另一个端口或设备的技术，用于实现内网服务对外访问和跨网络通信。**

## 基本概念

端口转发，也称端口映射，是通过路由器、服务器或软件将目标端口的流量重定向到另一个端口或 IP+端口组合的技术。它的核心作用包括：

- **隐藏真实服务端口**：例如将服务从非标准端口（如 8080）映射到标准端口（如 80），简化用户访问。
- **跨网络访问控制**：在内网与公网之间建立桥梁，使外部用户可以访问内网服务。
- **流量加密与隔离**：通过 SSH 隧道等方式加密传输敏感流量，或隔离不同服务的网络环境。

## 工作原理

端口转发通过将路由器或服务器的某个端口与内网设备的 IP 和端口绑定，实现流量定向转发。例如：

- 当路由器的 10000 端口收到数据时，将其转发到内网某台主机的对应端口。
- 当 20000 端口收到数据时，则转发到另一台主机。
  端口转发可分为：
- **目标 NAT（DNAT）**：修改数据包的目标 IP/端口，用于入站流量转发。
- **源 NAT（SNAT）**：修改数据包的源 IP/端口，用于出站流量伪装。

## 类型与应用

1. SSH 端口转发
   - **本地端口转发（-L）**：将本地端口流量通过 SSH 隧道转发到远程目标，例如 `ssh -L 8080:127.0.0.1:8000 user@server`，访问本地 8080 等同访问远程 8000 端口 。
   - **远程端口转发（-R）**：在远程服务器开端口，将流量转发到本地或其他主机，实现反向代理。
   - **动态端口转发（-D）**：生成 SOCKS 代理，所有流量通过 SSH 隧道传输。
2. 家庭或企业网络端口转发
   - 通过路由器将公网 IP 的端口映射到内网设备，实现外网访问内网服务，如 Web、远程桌面、监控或游戏服务器。
3. 内网穿透
   - 对于没有公网 IP 的设备，可通过 VPS 或 Cloudflare Tunnel 等工具建立“窗口”，让外部访问内网设备。

## 配置与工具

- **路由器端口转发**：在路由器管理界面配置公网端口与内网 IP+端口的映射。
- **Linux 系统**：可使用 `iptables`、`firewalld`、`SSH 隧道`、`frp`、`Gost` 等工具实现端口转发和内网穿透 。
- **安全注意**：建议使用加密隧道或 VPN，避免直接暴露内网服务到公网，防止安全风险。
