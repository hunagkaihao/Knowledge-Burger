# 快捷键

1. 折叠所有代码块：Ctrl + K + 0
2. 展开所有代码块：Ctrl + K + J
3. 全局搜索：Ctrl + Shift + F
4. 格式化：Alt + Shitf + F
4. 多行注释：shift +Alt + A

# 插件

## C# Dev Kit

`简介`：**C# Dev Kit** 是微软为 Visual Studio Code 打造的官方 C# 开发增强套件，它将语言服务、项目管理、测试运行和调试功能整合为一体，旨在让 VS Code 成为媲美 Visual Studio 的轻量级 .NET 开发环境。

**快捷键**：

1. F12 ：条状定义
2. Alt + ← ：返回原位

注意：占用内存多，根据电脑性能判断是否安装。
