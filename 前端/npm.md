# Vite 创建 Vue3 项目

## 1. **环境要求**

- Node.js 版本 **18+** 或 **20+**
- 检查版本：`node -v`

## 2. **创建项目**

### 方法一：使用 npm（推荐）

```bash
npm create vite@latest
```

然后按提示操作：

- 输入项目名称
- 选择框架：**Vue**
- 选择变体：**JavaScript** 或 **TypeScript**

# 依赖库

## Element Plus

**引入 UI 框架：** 安装并配置 Element Plus，利用其成熟的组件（如表格、表单、对话框）快速搭建页面。

```bash
npm install element-plus
```
