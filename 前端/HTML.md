# 概念

HTML（超文本标记语言）标签是构建网页的基石。它们告诉浏览器如何解释和显示内容。标签通常成对出现（开始标签和结束标签），但也有一些是自闭合的（空标签）。

# 文档结构标签（骨架）

| 标签              | 描述                      | 示例/备注                                  |
| ----------------- | ------------------------- | ------------------------------------------ |
| `<!DOCTYPE html>` | 声明文档类型 (HTML5)      | 必须放在文件第一行                         |
| `<html>`          | 根元素，包裹整个页面      | `<html lang="zh-CN">`                      |
| `<head>`          | 包含元数据 (不直接显示)   | 标题、编码、CSS 链接等                     |
| `<body>`          | 包含可见的页面内容        | 文本、图片、链接等都在此                   |
| `<meta>`          | 定义字符集、视口等元数据  | `<meta charset="UTF-8">`                   |
| `<title>`         | 定义浏览器标签页标题      | 显示在浏览器顶部标签栏                     |
| `<link>`          | 链接外部资源 (通常是 CSS) | `<link rel="stylesheet" href="style.css">` |
| `<script>`        | 嵌入或引用 JavaScript     | `<script src="app.js"></script>`           |

# 文本内容与排版标签（血肉）

**标题与段落**

| 标签            | 描述                    | 备注                          |
| --------------- | ----------------------- | ----------------------------- |
| `<h1>` - `<h6>` | 标题 (h1 最大，h6 最小) | SEO 重要，每页建议只有一个 h1 |
| `<p>`           | 段落                    | 自动在前后添加间距            |
| `<br>`          | 换行符                  | 强制换行，不产生新段落间距    |
| `<hr>`          | 水平分割线              | 表示主题分隔                  |

**文本样式**

| 标签           | 语义含义     | 默认视觉效果                     |
| -------------- | ------------ | -------------------------------- |
| `<strong>`     | 重要强调     | 粗体 (替代旧的 `<b>`)            |
| `<em>`         | 语气强调     | *斜体* (替代旧的 `<i>`)          |
| `<mark>`       | 高亮标记     | 黄色背景                         |
| `<small>`      | 附属小字     | 小号字体 (如版权信息)            |
| `<del>`        | 删除文本     | ~~删除线~~ (表示已删除)          |
| `<ins>`        | 插入文本     | 下划线 (表示新增)                |
| `<code>`       | 代码片段     | 等宽字体 (如 `console.log()`)    |
| `<pre>`        | 预格式化文本 | 保留空格和换行 (常配合 `<code>`) |
| `<blockquote>` | 块级引用     | 缩进显示大段引用                 |
| `<q>`          | 行内引用     | 自动添加双引号                   |

**列表标签**

| 标签   | 描述            | 示例结构                                  |
| ------ | --------------- | ----------------------------------------- |
| `<ul>` | 无序列表 (圆点) | `<ul><li>项 1</li><li>项 2</li></ul>`     |
| `<ol>` | 有序列表 (数字) | `<ol><li>第一步</li><li>第二步</li></ol>` |
| `<li>` | 列表项          | 必须位于 `<ul>` 或 `<ol>` 内部            |
| `<dl>` | 定义列表        | 用于术语和描述                            |
| `<dt>` | 定义术语        | `<dl><dt>HTML</dt><dd>标记语言</dd></dl>` |
| `<dd>` | 术语描述        |                                           |

**链接与媒体标签（交互与多媒体）**

| 标签           | 描述         | 关键属性                                                 |
| -------------- | ------------ | -------------------------------------------------------- |
| `<a>`          | 超链接       | `href` (地址), `target="_blank"` (新窗口)                |
| `<img>`        | 图像         | `src` (路径), `alt` (替代文本，重要!), `width`, `height` |
| `<video>`      | 视频播放器   | `controls`, `src`, `autoplay`, `loop`                    |
| `<audio>`      | 音频播放器   | `controls`, `src`                                        |
| `<iframe>`     | 内嵌框架     | 嵌入另一个网页 (如地图、YouTube)                         |
| `<figure>`     | 独立内容单元 | 通常包含图片和说明                                       |
| `<figcaption>` | 图表标题     | 位于 `<figure>` 内部                                     |

**语义化分区标签**

| 标签        | 描述         | 用途                                                   |
| ----------- | ------------ | ------------------------------------------------------ |
| `<header>`  | 页眉         | 网站 Logo、导航、主标题                                |
| `<nav>`     | 导航         | 主要导航链接组                                         |
| `<main>`    | 主要内容     | 页面独一无二的核心内容 (每页仅一个)                    |
| `<section>` | 章节         | 内容的一个独立部分 (如“关于我们”)                      |
| `<article>` | 文章         | 独立分发内容 (如博客文章、新闻)                        |
| `<aside>`   | 侧边栏       | 辅助内容 (广告、相关链接)                              |
| `<footer>`  | 页脚         | 版权信息、联系方式、网站地图                           |
| `<div>`     | 通用容器     | 无语义，仅用于 CSS 布局或 JS 操作 (滥用会导致结构混乱) |
| `<span>`    | 通用行内容器 | 无语义，用于包裹行内元素以添加样式                     |

**表格标签**

| 标签 | 描述       | 用途                   |
| ---- | ---------- | ---------------------- |
| `tr` | 行         | 定义表格中的行         |
| `th` | 标题单元格 | 定义表格中的标题单元格 |
| `td` | 数据单元格 | 定义表格中的数据单元格 |
