  # **WCS (Warehouse Control System**）

**WCS (Warehouse Control System)**：仓库控制系统。WMS 下达指令给 WCS，WCS 调度设备（堆垛机、输送线、AGV）执行。

 ## 特点

1. 系统集成：可以与其他企业级系统（如ERP、WMS）进行集成，实现信息的共享和流通
2. 任务调度：能够根据预设的规则和优先级自动安排和分配仓库内的各项任务（如入库、出库、拣货、搬运等）
3. 设备控制：可以与仓库内的各种设备进行集成和通信（如输送机、堆垛机、AGV等），实现对设备的实时控制和协调
4. 路径规划
5. 订单管理：支持订单的接收、处理和跟踪确保订单及时准确地完成
6. 数据分析和报告
