# 网关

## 前言

**网关（Gateway）** 是计算机网络中一种关键的网络设备或软件，用于**连接两个使用不同通信协议、数据格式或体系结构的网络**，并在它们之间进行**协议转换和数据转发**，使原本无法直接通信的网络能够互相交换信息。

### **一、核心作用**

网关的核心功能是 **“翻译” 和 “桥梁”**：

- 当两个网络使用的协议不同时（例如：TCP/IP 网络 ↔ IPX/SPX 网络，或局域网 ↔ 互联网），普通路由器无法处理。
- 网关工作在 **OSI 模型的高层（通常是传输层及以上，甚至应用层）**，能理解并转换不同协议的数据格式。

### **二、常见类型与应用场景**

| 类型                        | 说明                                   | 实际例子                                                     |
| --------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| 默认网关（Default Gateway） | 局域网内设备访问外网（如互联网）的出口 | 家庭 Wi-Fi 路由器的 IP（如 192.168.1.1）就是你电脑的默认网关 |
| 协议网关                    | 转换不同网络协议                       | 将 Modbus 协议转为 TCP/IP（工业物联网常用）                  |
| 语音/视频网关               | 连接传统电话网络（PSTN）与 VoIP 网络   | 公司用 SIP 网关实现网络电话拨打座机                          |
| API 网关                    | 微服务架构中统一管理 API 请求          | 控制访问、鉴权、限流、日志（如 Kong、Nginx）                 |
| IoT 网关                    | 连接传感器/设备与云平台                | 把 Zigbee、LoRa 设备数据转成 MQTT 上传到阿里云               |

### **三、网关 vs 路由器 vs 交换机**

| 设备             | 工作层级                | 主要功能                                   |
| ---------------- | ----------------------- | ------------------------------------------ |
| 交换机（Switch） | 数据链路层（第2层）     | 在同一局域网内转发数据帧（基于 MAC 地址）  |
| 路由器（Router） | 网络层（第3层）         | 在不同 IP 网络间路由数据包（基于 IP 地址） |
| 网关（Gateway）  | 传输层及以上（第4–7层） | 跨协议、跨架构的深度转换与通信             |
